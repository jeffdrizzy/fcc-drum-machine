# Drum Machine

A freeCodeCamp Front End Development Libraries project.

Nine drum pads (Q W E A S D Z X C). Click a pad or press its key to play the sound; the display shows the pad name. Sounds are the standard freeCodeCamp drum samples hosted on S3.

## Run

Open `index.html` in a browser, or serve the folder with any static server.

## Tests

The freeCodeCamp test suite is included via `https://cdn.freecodecamp.org/testable-projects-fcc/v1/bundle.js` — select "Drum Machine" in the test dropdown.
